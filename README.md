# VRChat VR Launcher

VRChat をデスクトップ版で多重起動したまま、指定したプロファイルを VR で後から起動するツールの配布用リポジトリです。
VR で起動した VRChat を、VR のままキーボード・マウス操作に切り替えることもできます。

ダウンロードは [Releases](https://github.com/Meltne/VRChatVRLauncher-Releases/releases/latest) から
`VRChat_VR_Launcher_vX.Y.Z.zip` を取得して展開してください。2 回目以降はアプリが自動で更新します。

困ったときはアプリ右上の「診断 ▾」→「診断情報をクリップボードへコピー」で情報をまとめて、開発者に送ってください。
